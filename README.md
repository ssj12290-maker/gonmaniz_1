# 우리끼리 경매

설치형 앱이 아닌 브라우저 기반 실시간 경매 웹앱입니다.

## 실행
1. Node.js 20 이상 설치
2. 이 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 `http://localhost:3000` 열기

## 친구들과 외부에서 사용하기
Render, Railway 등의 Node.js 호스팅에 이 폴더를 배포하세요. 시작 명령은 `npm start`입니다. 생성된 HTTPS 주소를 호스트가 열어 방을 만들고, **참가자 초대 링크**를 친구들에게 보내세요. TV용 공개 화면은 **공개 경매 화면 열기**를 사용하세요.

## 주의
- 서버 재시작 시 경매방과 정산 기록이 사라집니다. 중요한 정산 결과는 별도로 보관하세요.
- 호스트 URL에는 비밀 인증 토큰이 포함되므로 공유하지 마세요.
- 입찰자 접속 상태는 현재 브라우저 연결 기준입니다. 재접속 시 같은 닉네임으로 다시 입장할 수 있습니다.
- 실제 금전 거래가 아닌 친구들 간 놀이를 위한 MVP입니다.
